# La Feria

App web estatica de gestion para feria americana.

## Como probarla local

Abrir `index.html` en el navegador.

## Como subirla a Vercel

1. Subir esta carpeta a un repositorio de GitHub.
2. En Vercel, elegir `Add New Project`.
3. Importar el repositorio.
4. Dejar la configuracion por defecto para sitio estatico.
5. Publicar.

Vercel va a servir automaticamente `index.html`.

## Nota

Esta version guarda los datos en el navegador con `localStorage`. Para que el stock,
ventas, clientes y proveedores queden compartidos entre dispositivos, el siguiente
paso es conectar Supabase.
